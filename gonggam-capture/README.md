# 공감캡처

수업 화면을 찍고, 보고서까지 한 번에. Windows용 Electron 앱입니다.

`⬚ 캡처 → 📱 폰 사진 → ✎ 표시·모자이크 → 📝 보고서 PDF`

## 기능

| 기능 | 단축키 | 설명 |
| --- | --- | --- |
| 영역 캡처 | `Ctrl+Shift+2` | 화면을 멈춘 채 고릅니다. 확대경·픽셀 좌표·색상 코드, 실제 픽셀 크기 표시 |
| 직전 영역 다시 | `Ctrl+Shift+3` | 같은 자리를 키 하나로 다시 찍습니다 |
| 전체 화면 | `Ctrl+Shift+1` | 마우스가 있는 모니터 전체 |
| 마지막 캡처 편집 | `Ctrl+Shift+4` | 번호·텍스트·화살표·사각형·원·형광펜·펜·모자이크·자르기 |
| 수업 세션 | `Ctrl+Shift+5` | 반 이름을 정하면 이후 캡처·폰 사진에 자동으로 붙습니다. 자동 캡처(10초~3분)는 화면이 바뀔 때만 저장 |
| 폰으로 찍기 | `Ctrl+Shift+6` | QR 하나로 연결, 앱 설치 없음. 같은 와이파이에서 찍으면 라이브러리로 바로 들어옵니다 |
| 수업 보고서 | — | 사진을 골라 A4 PDF 로 저장. 학원명·담당은 설정값이 자동으로 들어갑니다 |
| 단축키 안내 | `?` | 앱 어디서나 |

영역 선택 중: `Enter`/`Space` 저장+복사 · `E` 저장 후 편집 · `B` 보고서에 담기 · `L` 직전 영역 · `F` 모니터 전체 · 방향키 1px(Shift 10px) · `Esc` 취소

전역 단축키는 설정에서 바꿀 수 있습니다(PrintScreen 한 키도 가능).

## 설치

1. `공감캡처-setup-1.0.0-x64.exe` 를 실행합니다. 관리자 권한 없이 내 계정에만 설치됩니다.
2. 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행** 을 누릅니다(코드 서명 인증서가 없어서 뜹니다).
3. 설치 후 알림 영역(시계 옆)에 아이콘이 상주합니다. 창을 닫아도 단축키는 계속 동작합니다.
4. 캡처는 `사진\공감캡처\날짜` 폴더에 저장됩니다. 앱을 지워도 사진은 남습니다.

폰 연결을 처음 열면 Windows 방화벽 창이 뜹니다. 「허용」을 눌러야 폰에서 접속됩니다.

## 설치파일 받기 · 만들기

- **GitHub Actions**: 이 폴더가 바뀌어 푸시되면 `공감캡처 Windows 설치파일` 워크플로가 Windows에서 빌드합니다.
  저장소의 Actions 탭 → 해당 실행 → Artifacts 의 `gonggam-capture-setup` 을 받으면 설치파일이 들어 있습니다.
- **직접 빌드** (Node.js 22 이상):

  ```
  cd gonggam-capture
  npm install
  npm start        # 개발 실행
  npm run dist     # dist\공감캡처-setup-1.0.0-x64.exe 생성
  ```

## 구조

```
src/main.js            메인 프로세스 — 캡처, 저장, 단축키, 트레이, 세션, PDF
src/phone-server.js    폰 업로드용 로컬 웹 서버 (주소의 토큰을 아는 기기만 업로드)
src/overlay/           영역 선택 화면
src/renderer/          라이브러리 · 편집기 · 보고서 · 설정
src/mobile/            폰에서 열리는 화면
src/shared/            보고서 HTML (미리보기와 PDF 가 같은 코드를 씁니다)
test/smoke.js          가상 화면에서 주요 흐름을 돌려 보는 점검 스크립트
```

데이터 위치: 사진은 `사진\공감캡처`, 목록·설정은 `%APPDATA%\공감캡처`.
